# Keel Engineering Context

Use `keel rules match <paths...>` before non-trivial edits. Record multi-step contracts with `keel task create` and retrieve past decisions with `keel mem search`.
When calling `keel_*` MCP tools, pass the target repository path as `root` whenever known.
Run `keel verify` before finishing. Prefer executable gates over prose; keep rules scoped to non-obvious invariants. Keel does not prescribe how your agent schedules work.
